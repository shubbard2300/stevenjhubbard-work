MEND Medical Wear

Founder, Architect & Developer · 2026 – Present

Recovery apparel and connected-care, built end to end — positioning, identity, storefront, seven product pages, and a React assessment tool, all of it mine.

Soft washable recovery gowns, residential nurse scrubs, medical-grade compression socks, the AirGuard™ fall-detection collar, and the connected devices around them — a brand aimed at patients and at the people caring for them. I own every layer: the positioning, the identity, the product pages, the storefront architecture, and the code.

The storefront is hand-written static HTML, CSS, and JavaScript on Vercel. No framework, no build step for the site proper. That is a deliberate architectural call rather than a shortcut — a catalogue this size does not need a bundler, and skipping one buys near-instant loads and a site that will still build in five years without a dependency archaeology dig.

The exception is the fall-risk assessment tool, the site’s lead magnet: a React application scoring fall risk against WHO data, with charts and a regional model. It runs through hand-written React shims rather than a bundler, so one interactive tool did not drag a toolchain onto the whole project.

  • Seven product detail pages — gowns, scrubs, compression socks, the AirGuard™ collar, MEND Pulse, MEND Oxi, and the MEND app
  • React fall-risk assessment built on WHO fall data, wired to a serverless lead-capture endpoint
  • Full technical SEO program: www unification, clean product slugs, an image pipeline, security headers, sitemap and robots
  • Static-first architecture — no build step for the storefront, no framework lock-in
